1. Robot systems

Topic: A robot is a system

An advanced robot is not one motor. It is a system of power, sensing, computing, and motion. If one block fails, the whole behavior fails. Engineers name the blocks before they build.

Topic: The control loop

The loop is read, estimate, decide, command, then read again. A beginner robot may only compare distance with 20 cm. An advanced robot also remembers the last command so it does not jitter between turn and forward.

Topic: States

Give the robot named states: Search, Approach, Avoid, Stop. It can be in only one state at a time. A sensor event moves it to the next state. This is clearer than a long chain of if statements.

state = "Search" if distance < 20: state = "Avoid" elif distance < 40: state = "Approach" else: state = "Search"
Case. A delivery robot searches until a wall is near, switches to Avoid, turns until the path is clear, then returns to Search. The state name is what you print when you test.
Safety: add a Stop state that cuts motor commands if a button is pressed or a sensor reading is impossible.

Check: what should a robot be in, one at a time?

2. Sensing and signals

Topic: A reading is not the world

A sensor reports a number. That number can be late, noisy, or wrong. Advanced work asks: what was measured, in what unit, and what reading is impossible?

Topic: Ultrasonic distance

An ultrasonic sensor sends a sound pulse and times the echo. Distance is about speed of sound times time, divided by two because the sound goes out and back. A soft curtain can give a weak echo. A very close object can be missed.

Topic: Filtering

Do not trust one sample. Take three readings and use the middle one, or average the last five. This is a simple filter. It stops one bad reading from turning the robot.

Topic: Calibration

Put a book at 20 cm. If the sensor says 26 cm, record the offset. Subtract that offset in code, or change the decision limit. Write the test in your notes.

Case. Readings 21, 19, 48. The 48 is a missed echo. The middle value is 21, so the robot keeps the 21 cm decision.

Check: why divide the echo trip by two?

3. Control decisions

Topic: Open loop and closed loop

Open loop plays a command and does not check the result. Closed loop measures the result and corrects. A timed turn is open loop. A turn-until-the-path-is-clear is closed loop.

Topic: Error

Error is the target minus the measurement. If the target distance is 25 cm and the sensor reads 15 cm, the error is 10 cm. The controller uses error to choose a command.

Topic: A simple proportional idea

A bigger error can make a stronger correction. If the arm is 40 degrees away from the goal, move faster. If it is 5 degrees away, move slower. That idea is called proportional control. Too strong a correction makes the joint overshoot and wobble.

error = target - measured if abs(error) < 3: stop() elif error > 0: move_positive() else: move_negative()
Case. Line follower: left sensor sees the line and right does not. Error says drift right, so the right wheel slows. Both sensors see the line, error is near zero, both wheels match.

Check: target minus measurement is called what?

4. Motion and mechanics

Topic: Force, torque, and grip

Force pushes the robot. Torque turns a wheel or joint. Friction lets the tire push the floor. If torque is high and friction is low, the wheel spins and the robot does not move.

Topic: Differential drive

Two driven wheels can steer without a steering axle. Equal wheel speeds go straight. A faster left wheel turns the robot right. Opposite wheel directions spin in place. This is the standard base before legs.

Topic: Gearing

A small gear driving a large gear reduces speed and increases torque. Use that when a robot must start under load. Record the gear ratio in the build notes so later speed calculations match the real robot.

Topic: Stability

Keep the center of mass low and inside the wheelbase. A tall mast with a heavy part on top tips on a small bump. Move mass down before you add more speed.

Test turns slowly. A fast spin can walk the robot off a table. Use a barrier or test on the floor.

Check: two wheels steering by speed difference is called what drive?

5. Arms and position

Topic: Joint space

An arm is described by joint angles. A two-servo arm has a base angle and an elbow angle. Moving in joint space means you command angles, not a point in the room.

Topic: A pose

A pose is a saved set of angles. Home might be 90 and 40. Reach might be 90 and 110. Wave might be 40 then 140 on the shoulder. Store poses in a table so a mission is a list of poses, not guesses.

Topic: One joint at a time

Advanced-looking motion is still built from safe steps. Move the elbow, wait until it arrives, then move the base. If both jump at once, you cannot tell which joint caused a problem.

poses = { "home": (90, 40), "reach": (90, 110), "wave": (140, 40) }
Case. Pick mission: home, reach, close a gripper delay, home. Write the angles you measured, not angles you only imagined.

Check: a saved set of joint angles is called a what?

6. Humanoid plan

Topic: A humanoid is integrated systems

A humanoid robot joins structure, many actuators, balance sensing, power, and a program of small moves. It is not a costume on a wheeled robot. The wheeled robot and the arm are the training systems.

Topic: Behavior layers

Use layers. The lowest layer commands one joint. The next layer plays a pose. A higher layer plays a gesture such as wave. The top layer chooses a mission. When a layer fails, you test the layer under it.

Topic: Balance before steps

Standing fails if the center of mass leaves the feet. A tilt reading can trigger a recover pose. Walking is a sequence: shift weight, lift, place, shift back. Do this with support before a free step.

Topic: Engineering order

  1. Differential-drive robot with a tested avoid state.
  2. Two-servo arm with named poses.
  3. Wave gesture from those poses.
  4. Supported stand and a tilt check.
  5. One short step, then stop and review.
Case. Wave gesture calls shoulder poses 40, 140, 40 with waits. If the shoulder never reaches 140, fix that pose before you add a second arm.

Check: what should you build before a free step?
