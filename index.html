🔧 Project Missions

🚗

1. Obstacle-Avoiding Robot

Parts: two motors, a motor driver, an ultrasonic sensor, and a controller board.

  1. Wire the sensor and motors.
  2. Read distance.
  3. Drive forward if the path is clear.
  4. Stop and turn if distance is under 20 cm.
🦾

2. Robotic Arm

Parts: two or three servo motors and a light arm.

  1. One servo is the base.
  2. One servo is the elbow.
  3. Move one joint at a time.
  4. Write down each angle you use.
🤖

3. Humanoid Robot

A long mission. Start only after missions 1 and 2.

  1. Balance on two legs.
  2. Add sensors so it knows it is tipping.
  3. Program small steps.
  4. Add a simple task, like waving.
